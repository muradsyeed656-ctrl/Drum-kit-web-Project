# Drum Kit 🥁

Hi! This is my Drum Kit project. I made it with HTML, CSS and JavaScript.

You can play drums just by clicking on the buttons, or by pressing keys on your keyboard.

## Live Demo

Play My Drum Kit: PASTE_YOUR_GITHUB_PAGES_LINK_HERE

## Features

- 7 drums: w - Crash, a - Kick Bass, s - Snare, d - Tom 1, j - Tom 2, k - Tom 3, l - Tom 4
- Play with mouse click
- Play with keyboard - Press W A S D J K L
- Button press animation when you play
- Real drum sounds with new Audio().play()
- Dark blue background #283149, white drums, Arvo font

## Components

- index.html - Structure, heading Drum Kit, 7 buttons inside div class set, footer Made with ❤️ in Pakistan.
- styles.css - Design, background #283149, heading and footer color #DBEDF3, drum buttons white, font Arvo, border 10px solid #404B69
- index.js - Logic, querySelectorAll(".drum"), click listener, keydown listener, makeSound() with switch, buttonAnimation() with pressed class and setTimeout 100ms
- images folder - crash.png, kick.png, snare.png, tom1.png, tom2.png, tom3.png, tom4.png
- sounds folder - crash.mp3, kick-bass.mp3, snare.mp3, tom-1.mp3, tom-2.mp3, tom-3.mp3, tom-4.mp3

## Dependencies

- No need to install anything
- Just a browser like Chrome
- Google Fonts Arvo - already linked in index.html

## Minimal Workflow

1. Download this folder
2. Open index.html in browser
3. Click a drum or press W A S D J K L
4. Hear sound and see animation
